# اختبارات الانحدار — بصير · عيون المالك

اختبارات متصفح حقيقية (Playwright) تشغّل التطبيق في **وضع الديمو** داخل المتصفح بلا خادم،
عبر اعتراض الطلبات وتقديم ملفات المستودع مباشرة. الغرض: التأكد قبل كل نشر أن الأدوار
الخمسة وكل الصفحات والتبويبات والأزرار والسلاسل الأساسية تعمل بلا أخطاء.

## التثبيت (مرة واحدة)

```bash
npm i -D playwright
npx playwright install chromium
```

> إن كان لديك متصفح Chromium جاهز (مثلاً على خادم CI)، صدّر مساره لتخطّي التنزيل:
> `export CHROME_PATH=/path/to/chrome`

## التشغيل

```bash
node tests/roles-smoke.js            # كل الأدوار الخمسة: كل صفحة تُصيّر بلا أخطاء JS
node tests/crawl-all.js              # زحف شامل: كل تبويب/فلتر/زر/نافذة لكل دور
node tests/drawing-boq-brightness.js # السلسلة: مستخلص → اعتماد → إضاءة المخطط (مظلم←ساطع)
node tests/bim-render.js             # عرض نموذج BIM الحقيقي (IFC) بعشرات العناصر
node tests/e2e-cycle.js              # دورة «يوم في الموقع»: رفع WIR/RFI/مواد + اعتماد
```

كل اختبار يخرج بالرمز `0` عند النجاح و`1` عند الفشل (مناسب لـ CI).
الصور الناتجة تُحفظ في `tests/output/` (خريطة الإنجاز قبل/بعد، ونموذج BIM).

## أداة توليد نموذج BIM

```bash
node tests/gen-ifc.js [مسار الإخراج]
```

يولّد ملف IFC4 صالحاً لبرج متعدد الأدوار (بلاطات، أعمدة، نواة، جدران، واجهة زجاجية)
— الافتراضي: `public/vendor/bim/BassirTower.ifc`.

## ملاحظات

- الاختبارات تشارك قاعدة بيانات الديمو عبر تسجيلات الدخول (لمحاكاة عدة مستخدمين على
  نفس المشروع)، وتُصفَّر بين كل تشغيل.
- المنطق نفسه يعمل على الخادم الحقيقي؛ في الديمو تُحاكى المرفقات بالاسم (بلا تخزين).
